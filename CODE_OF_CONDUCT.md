# Code of Conduct

Be respectful, constructive, and privacy-conscious. Harassment, discrimination, doxxing, or publishing credentials or identifiable student data is not acceptable.

Project discussions should stay focused on reproducible technical behavior. Maintainers may edit or remove content, issues, pull requests, or participation that threatens student privacy, community safety, or project security.

Report conduct concerns privately to the maintainer through the contact options on the maintainer's GitHub profile. Do not include student information in a report.
